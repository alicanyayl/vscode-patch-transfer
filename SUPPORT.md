# Support

If you encounter issues or have questions about **Patch Transfer**, please use the resources below.

## Reporting Issues

Bug reports and feature requests should be submitted through GitHub Issues:

👉 [https://github.com/alicanyayl/vscode-patch-transfer/issues](https://github.com/alicanyayl/vscode-patch-transfer/issues)

### When Reporting a Bug

Please provide the following information to help us diagnose the issue quickly:
- **Patch Transfer Version**: (e.g., `0.1.0`)
- **VS Code Version**: (e.g., `1.134.0`)
- **Git Version**: (Run `git --version`)
- **Operating System**: (Windows, macOS, Linux)
- **Patch Status**: (`READY`, `CONFLICT`, `INVALID`, etc.)
- **Steps to Reproduce**: Clear step-by-step instructions
- **Conflict Diagnostics**: If reporting a conflict issue, paste the diagnostics generated by **Copy Conflict Diagnostics**.

> [!CAUTION]
> **Confidentiality Warning**: Never post sensitive code, private patch contents, credentials, internal IP addresses, or proprietary tokens in public issue reports.
