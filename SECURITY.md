# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The Patch Transfer maintainers take security seriously.

If you discover a security vulnerability in this project:

1. **Do not disclose the issue publicly** via open GitHub issues, public pull requests, or social media.
2. Please use **GitHub Private Vulnerability Reporting** on the repository page:
   [https://github.com/alicanyayl/vscode-patch-transfer/security/advisories/new](https://github.com/alicanyayl/vscode-patch-transfer/security/advisories/new)
3. If private vulnerability reporting is not yet enabled on the repository, please contact the repository owner privately or submit an issue requesting private contact before sharing sensitive vulnerability details.

### What to Include

- A detailed description of the vulnerability.
- Steps or proof-of-concept to reproduce the behavior.
- Any potential impact on offline environments or file integrity.

Thank you for responsibly disclosing vulnerabilities.
